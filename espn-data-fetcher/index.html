Data Fetcher for ESPN Fantasy

A Chrome extension and iOS Safari extension that brings back opponents, game status and past-day stats on ESPN Fantasy Basketball roster and Players pages when they load empty outside the US.

In some regions the browser's requests to ESPN's stats API, site.api.espn.com, are refused with "Access Denied". ESPN serves the same data on site.web.api.espn.com. On fantasy.espn.com only, the extension changes the address of those requests to that host before they are sent. It collects no data.

Install it from the Chrome Web Store, or on iPhone and iPad from the App Store and turn it on in Settings › Apps › Safari › Extensions, then reload the ESPN Fantasy page.
