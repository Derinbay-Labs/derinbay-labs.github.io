Data Fetcher for ESPN Fantasy privacy policy

Last updated: 2026-10-26

What the extension does

The extension contains one static Chrome declarativeNetRequest rule. When a page on fantasy.espn.com requests data from site.api.espn.com, Chrome sends that request to site.web.api.espn.com instead. Chrome applies the rule itself; the extension has no code that runs.

What data it collects

None. The extension does not read, store, transmit, sell or share any personal or browsing data. It has no background script, no content script, no storage and no analytics. Derinbay Labs runs no server for it.

Third parties

Requests the ESPN page already makes still go to ESPN, under ESPN's own privacy policy. The extension adds no other recipient.

Removing it

Remove the extension from chrome://extensions at any time; the rule stops immediately.
