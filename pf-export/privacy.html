pf-export privacy policy

Last updated: 2026-10-11

What the app accesses

pf-export requests only the Google Drive drive.file scope. With this scope it can see and change only the files it creates itself, which are one folder, personal-finance-export, and one file in it, portfoy.csv. It cannot read or list any other file in your Drive.

What data it handles

The CSV holds the owner's own open investment positions, generated on the owner's own computer. pf-export reads no Google user data. It does not use, store, share or sell Google user data, and does not transfer it to any third party.

Where data is stored

The OAuth token is stored only on the owner's computer, in a file only that user account can read. Derinbay Labs runs no server for this app and collects no analytics.

Revoking access

Remove pf-export at myaccount.google.com/connections at any time. Removing it stops all access immediately.

Google API use complies with the Google API Services User Data Policy, including its Limited Use requirements.
