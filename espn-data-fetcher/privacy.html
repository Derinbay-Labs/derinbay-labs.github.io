Data Fetcher for ESPN Fantasy privacy policy

Last updated: 2026-10-26

What the extension does

The extension contains one small script, the same in the Chrome extension and the iOS Safari extension, that runs only on fantasy.espn.com. When that page requests data from site.api.espn.com, the script changes the address to site.web.api.espn.com before the request is sent. It reads no page content and makes no requests of its own; the iOS app only shows setup steps.

What data it collects

None. The extension does not read, store, transmit, sell or share any personal or browsing data. It has no background script, no storage and no analytics. Derinbay Labs runs no server for it.

Third parties

Requests the ESPN page already makes still go to ESPN, under ESPN's own privacy policy. The extension adds no other recipient.

Removing it

Remove the extension from chrome://extensions, turn it off in iOS Settings › Apps › Safari › Extensions, or delete the iOS app at any time; the script stops immediately.
